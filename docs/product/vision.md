# E-Reader Project

## O que é
Um projeto pessoal, sem expectativas comerciais. A ideia é que seja um gerenciador de biblioteca de leitores de epub, com público-alvo inicial o usuário de Amazon Kindle.


## Público inicial
Usuário do leitor Amazon Kindle, que desejam mais facilidade para organizar sua biblioteca e transferir arquivos e livros para seus dispositivos.

## Proposta de valor
Gerencie sua biblioteca de epubs de onde estiver, faça upload e download dos seus arquivos, gerencie suas coleções, organize os livros, ajustes informações, leia mais sobre, encontre ofertas e análises de sistes como Amazon, e ao final, envie diretamente ao seu dispositivo.

## Caso de uso primário
Usuário faz o upload do arquivo, os metadados são lidos e processados, a capa é adicionada, e ele pode enviar o livro para seu dispositivo Kindle.

## O que não é
Uma loja ou plataforma para compra/download/compartilhamento de livros digitais, não se responsabilizando pelo material provido pelo usuário.

## Features desejadas no MVP
- Painel de controle administrativo, com gestão de usuários.
- Upload de arquivos Epub/PDF/Mobi
- Processamento destes arquivos e extração de metadados
- Processamento e uso dos metatadados para compor a biblioteca de cada usuário
- Envio para Kindle através da web utilizando o envio de arquivos via e-mail
- Possibilidade de adicionar avaliação e status de leitura dos arquivos
- Incluir arquivos em coleções para melhor organização da biblioteca.
- Interface clara e amigável.

## Features não desejadas:
- Compartilhamento de arquivos entre usuários
